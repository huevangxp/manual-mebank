  2. ປ້ອນ Username / Staff ID ແລະ Password ປະຈຳຕົວຂອງທ່ານ.

Configure System Roles and Segregation of Duties

ທະນາຄານ APB ນຳໃຊ້ຫຼັກການ Dual Control (Maker-Checker) ເພື່ອຄວາມປອດໄພສູງສຸດ:

Maker Role (ຜູ້ສ້າງ / ຜູ້ຮ້ອງຂໍ)

ມີສິດປ້ອນຂໍ້ມູນ, ສ້າງຜູ້ໃຊ້ງານ, ສ້າງບັດປະທານ (Create Chairman Card), ແຕ່ບໍ່ສາມາດອະນຸມັດລາຍການຂອງຕົນເອງໄດ້.

Checker Role (ຜູ້ກວດສອບ / ຜູ້ອະນຸມັດ)

ມີສິດກວດສອບຂໍ້ມູນ, ອະນຸມັດ (Approve) ຫຼື ສົ່ງກັບ (Reject) ຄຳຮ້ອງຂໍທີ່ Maker ສົ່ງມາ. ບໍ່ສາມາດສ້າງລາຍການເອງໄດ້.

ຕົວຢ່າງສຳຄັນ: ຖ້າຕ້ອງການໃຫ້ພະນັກງານມີສິດເຂົ້າເມນູ "ສ້າງບັດປະທານ (Create Chairman Card)" ໃຫ້ເລືອກ Role: Card Management Operator.

ຂັ້ນຕອນນີ້ເປັນການຈຳກັດຂອບເຂດຂໍ້ມູນທີ່ຜູ້ໃຊ້ງານສາມາດເບິ່ງເຫັນ ແລະ ຈັດການໄດ້ ເພື່ອປ້ອງກັນການເຂົ້າເຖິງຂໍ້ມູນຂ້າມສາຂາ.

1 Data Scope: ເລືອກ "All Branches" ສຳລັບພະນັກງານສຳນັກງານໃຫຍ່ ຫຼື ສູນບັດ VIP. ເລືອກ "Single Branch" ສຳລັບພະນັກງານສາຂາ.
2 Approval Limit: ກຳນົດວົງເງິນອະນຸມັດສູງສຸດຕໍ່ວັນ ຕາມລະດັບຕຳແໜ່ງທີ່ໄດ້ຮັບອະນຸມັດຈາກຄະນະບໍລິຫານ.

Maker Review and Submission for Dual Authorization

ກວດສອບຄວາມຖືກຕ້ອງຂອງຂໍ້ມູນທັງໝົດກ່ອນກົດປຸ່ມຢືນຢັນ. ເມື່ອກົດສົ່ງແລ້ວ ລະບົບຈະບັນທຶກສະຖານະເປັນ Pending Approval.

ສິ່ງທີ່ຕ້ອງກວດກາ:

  • ກວດເບິ່ງວ່າ Staff ID ແລະ ອີເມລຖືກຕ້ອງຕາມລະບົບ HR.
  • ກວດສອບວ່າ Role ທີ່ກຳນົດບໍ່ເກີນສິດທິໜ້າທີ່ຮັບຜິດຊອບ (Least Privilege Principle).
