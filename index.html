ຄູ່ມືການຊຳລະບິນ ແລະ ຈອງປີ້ເຮືອບິນ: ລາວເດີນອາກາດ (Lao Skyway)

ຄູ່ມືແນະນຳລະອຽດທຸກຂັ້ນຕອນຕັ້ງແຕ່ການເຂົ້າເມນູຊຳລະບິນ, ການເລືອກຜູ້ໃຫ້ບໍລິການ ລາວເດີນອາກາດ, ການປ້ອນຂໍ້ມູນຄົ້ນຫາຖ້ຽວບິນທຸກຊ່ອງ (Every Input Field), ການກົດຄົ້ນຫາ (Search Flight) ຈົນເຖິງການເລືອກຖ້ຽວບິນ ແລະ ກົດປຸ່ມຕໍ່ໄປ (Continue).

Header Bill Payment Menu & Lao Skyway Selection

ພາບປະກອບຕອນທີ 1 (Screen 1 View)
1

ຂັ້ນຕອນທີ 1: ກົດເລືອກເມນູ "ຊຳລະບິນ" (Bill Payment) ຢູ່ແຖບ Header ດ້ານເທິງ

ຢູ່ເທິງສຸດຂອງໜ້າຈໍໃນແຖບເມນູຫຼັກ (Navigation Bar), ໃຫ້ຄລິກເລືອກເມນູ "ຊຳລະບິນ" (ໄອຄອນຮູບໃບບິນສີເຫຼືອງ ຖັດຈາກເມນູ "ໂອນເງິນ"). ເມື່ອຄລິກແລ້ວ ລະບົບຈະພາທ່ານເຂົ້າສູ່ສູນກາງການຊຳລະຄ່າບໍລິການຕ່າງໆ.

2

ຂັ້ນຕອນທີ 2: ເລື່ອນລົງມາທີ່ໝວດ "ຈອງປີ້ເຮືອບິນ" ແລ້ວກົດ "ລາວເດີນອາກາດ" (Lao Skyway)

ໃນໜ້າຊຳລະບິນ ໃຫ້ເລື່ອນລົງມາຫາໝວດ "ຈອງປີ້ເຮືອບິນ" (Flight Booking), ຈາກນັ້ນກົດເລືອກທີ່ໂລໂກ້ "ລາວເດີນອາກາດ" (Lao Skyway) (ໄອຄອນຮູບນົກສີຂຽວ) ເພື່ອກ້າວເຂົ້າສູ່ໜ້າລະບົບຄົ້ນຫາ ແລະ ຈອງປີ້ໂດຍສານ.

2

ຕອນທີ 2: ປ້ອນຂໍ້ມູນຄົ້ນຫາຖ້ຽວບິນ ແລະ ກົດຕໍ່ໄປ (Flight Search & Continue)

Fill Flight Details, Click Search Flight, Select Ticket, and Click Continue

ພາບປະກອບຕອນທີ 2 (Screen 2 View)

ອະທິບາຍລະອຽດທຸກຊ່ອງຂໍ້ມູນ (Field-by-Field Breakdown)

1. ປະເພດການເດີນທາງ Trip Type
ເລືອກ: "ຖ້ຽວດຽວ" ຫຼື "ໄປ-ກັບ"

• ຖ້ຽວດຽວ (One-Way): ສຳລັບການເດີນທາງຂາໄປພຽງຢ່າງດຽວ (ຕົວຢ່າງເລືອກຖ້ຽວດຽວ ພ້ອມເຄື່ອງໝາຍຕິກຖືກ).
• ໄປ-ກັບ (Round-Trip): ສຳລັບການເດີນທາງທັງຂາໄປ ແລະ ຂາກັບ.

2. ຕົ້ນທາງ From / Origin
ຈາກ (Departure Airport)

ເລືອກສະໜາມບິນຕົ້ນທາງທີ່ຕ້ອງການຂຶ້ນຍົນ, ຕົວຢ່າງ: VTE - Vientiane (ສະໜາມບິນສາກົນວັດໄຕ, ນະຄອນຫຼວງວຽງຈັນ).

3. ປາຍທາງ To / Destination
ເຖິງ (Arrival Airport)

ເລືອກສະໜາມບິນປາຍທາງທີ່ຈະລົງ, ຕົວຢ່າງ: XKH - Xieng Khouang (ສະໜາມບິນແຂວງຊຽງຂວາງ).

4. ວັນທີເດີນທາງ Travel Date
ວັນທີເດີນທາງ (Date Picker)

ຄລິກໃສ່ປະຕິທິນເພື່ອເລືອກວັນ, ເດືອນ, ປີ ທີ່ຕ້ອງການບິນ, ຕົວຢ່າງ: 14/10/2026 (ຫາກເລືອກໄປ-ກັບ ຈະມີຊ່ອງວັນທີກັບໃຫ້ເລືອກເພີ່ມ).

5. ຜູ້ໂດຍສານ Passengers
ຈຳນວນຜູ້ໂດຍສານ (Passenger Count)

ເລືອກຈຳນວນຄົນເດີນທາງ: 1 ຜູ້ໃຫຍ່, 0 ເດັກນ້ອຍ, 0 ເດັກອ່ອນ (ສາມາດກົດເພີ່ມ ຫຼື ຫຼຸດຈຳນວນຄົນໄດ້ຕາມຄວາມຕ້ອງການ).

6. ຊັ້ນໂດຍສານ Cabin Class
ຊັ້ນໂດຍສານທີ່ຕ້ອງການ (Class)

ເລືອກລະດັບຊັ້ນທີ່ນັ່ງ, ຕົວຢ່າງ: Economy (ຊັ້ນປະຢັດ) ຫຼື Business Class (ຖ້າມີເປີດໃຫ້ບໍລິການ).

7. ລະຫັດໂປຣໂມຊັນ Promo Code (Optional)
ລະຫັດໂປຣໂມຊັນ (Discount / Voucher)

ປ້ອນລະຫັດສ່ວນຫຼຸດພິເສດຈາກ APB ຫຼື Lao Skyway (ຖ້າມີ) ເພື່ອຮັບສ່ວນຫຼຸດຄ່າປີ້. ຫາກບໍ່ມີລະຫັດ ແມ່ນສາມາດປະວ່າງໄວ້ໄດ້ເລີຍ.

2

ຂັ້ນຕອນທີ 2: ກົດປຸ່ມ "ຄົ້ນຫາຖ້ຽວບິນ" (Click Search Flight)

ຫຼັງຈາກປ້ອນຂໍ້ມູນການເດີນທາງທຸກຊ່ອງຄົບຖ້ວນແລ້ວ, ໃຫ້ກົດທີ່ປຸ່ມສີຂຽວເຂັ້ມ "ຄົ້ນຫາຖ້ຽວບິນ" ຢູ່ດ້ານລຸ່ມຂອງຟອມ. ລະບົບຈະເຊື່ອມຕໍ່ກັບຖານຂໍ້ມູນຖ້ຽວບິນຂອງ Lao Skyway ແລະ ສະແດງລາຍການຖ້ຽວບິນທີ່ວ່າງຢູ່ດ້ານຂວາມື.

3

ຂັ້ນຕອນທີ 3: ເລືອກຖ້ຽວບິນທີ່ຕ້ອງການ (Select Flight Card)

ຢູ່ຖັນດ້ານຂວາ ລະບົບຈະສະແດງກາດຖ້ຽວບິນທີ່ພົບ:

ຖ້ຽວບິນ:LK212
ປະເພດຍົນ:MA60
ເວລາ:15:10 VTE → 15:45 XKH
ລາຄາ:710,000.00 LAK (ຍັງເຫຼືອ 5 ບ່ອນ)

👉 ຄລິກໃສ່ກາດຖ້ຽວບິນນີ້ ເພື່ອເລືອກຖ້ຽວບິນທີ່ຕ້ອງການເດີນທາງ.

4

ຂັ້ນຕອນທີ 4: ກົດປຸ່ມ "ຕໍ່ໄປ" (Click Continue)

ເມື່ອເລືອກຖ້ຽວບິນຮຽບຮ້ອຍແລ້ວ, ໃຫ້ກົດປຸ່ມສີຂຽວ "ຕໍ່ໄປ" (Continue) ທີ່ມີໄອຄອນຕິກຖືກ ຢູ່ດ້ານລຸ່ມຂວາມື (ຂ້າງປຸ່ມ "ກັບຄືນ") ເພື່ອກ້າວເຂົ້າສູ່ຂັ້ນຕອນຕໍ່ໄປ: ປ້ອນຊື່ຜູ້ໂດຍສານ ແລະ ຊຳລະເງິນ.

📋 ສະຫຼຸບຂັ້ນຕອນທັງໝົດ (Workflow Summary)

ການຈອງ ແລະ ຊຳລະບິນປີ້ເຮືອບິນ Lao Skyway ຜ່ານ APB MeBank ມີຂັ້ນຕອນງ່າຍໆຄື:

1. ເຂົ້າເມນູ ກົດ "ຊຳລະບິນ" ຢູ່ Header
2. ເລືອກສາຍການບິນ ກົດ "ລາວເດີນອາກາດ"
3. ຄົ້ນຫາ & ເລືອກ ປ້ອນຂໍ້ມູນ, ກົດ "ຄົ້ນຫາຖ້ຽວບິນ" ແລະ ເລືອກຖ້ຽວບິນ
4. ຕໍ່ໄປ & ຊຳລະ ກົດ "ຕໍ່ໄປ" ປ້ອນຊື່ ແລະ ຢືນຢັນ PIN/OTP
