ດາວໂຫຼດ PDF ຕົ້ນສະບັບ
ຄູ່ມືການນຳໃຊ້ລະບົບ Admin Portal Mebank 16 ຄູ່ມື

1. ວິທີການສ້າງບໍລິສັດ (Create Corporate)

ສ້າງຂໍ້ມູນບໍລິສັດແມ່, ອັບໂຫຼດເອກະສານ 7 ລາຍການ, ຜູກ CIF ແລະ ເພີ່ມຜູ້ໃຊ້ Maker/Checker

ເບິ່ງຄູ່ມື (View)

2. ວິທີການສ້າງບໍລິສັດລູກ (Create Sub Corporate)

ເລືອກບໍລິສັດແມ່, ປ້ອນຂໍ້ມູນບໍລິສັດລູກ, ອັບໂຫຼດເອກະສານ, ເພີ່ມບັນຊີ CIF ແລະ ຜູ້ໃຊ້

ເບິ່ງຄູ່ມື (View)

3. ການສ້າງຢູເຊີບໍລິສັດ (Create User Corporate & Sub)

ເພີ່ມຜູ້ໃຊ້ໃໝ່ເຂົ້າໃນບໍລິສັດແມ່ ຫຼື ບໍລິສັດລູກ ແລະ ກຳນົດສິດ Maker / Checker / Admin Portal

ເບິ່ງຄູ່ມື (View)

4. ການສ້າງບໍລິສັດສ່ວນບຸກຄົນ (Create Individual)

ສ້າງຜູ້ໃຊ້ໃໝ່ສຳລັບລູກຄ້າບຸກຄົນທົ່ວໄປ / ບໍລິສັດສ່ວນບຸກຄົນ, ອັບໂຫຼດເອກະສານ ແລະ ຜູກ CIF

ເບິ່ງຄູ່ມື (View)

5. ວິທີການເພີ່ມບັນຊີບໍລິສັດ (Create Account Master)

ເພີ່ມເລກບັນຊີທະນາຄານເຂົ້າໃນບໍລິສັດຜ່ານເມນູ System management → Account

ເບິ່ງຄູ່ມື (View)

6. ວິທີການອະນຸມັດລາຍການ (Approve Pending Requests)

ກວດສອບລາຍການສະຖານະຄ້າງຢູ່ (Pending), ກວດລາຍລະອຽດ 3 ສ່ວນ ແລະ ກົດອະນຸມັດ/ປະຕິເສດ

ເບິ່ງຄູ່ມື (View)

1. ການແກ້ໄຂຂໍ້ມູນຜູ້ໃຊ້ (Update User)

ຄົ້ນຫາຜູ້ໃຊ້ ແລະ ແກ້ໄຂຊື່ເຕັມ, ອີເມວ, ເບີໂທຕິດຕໍ່, ວັນເດືອນປີເກີດ, ທີ່ຢູ່ ຫຼື ຮູບຜູ້ໃຊ້

ເບິ່ງຄູ່ມື (View)

2. ການລົບຜູ້ໃຊ້ (Delete User)

ຄົ້ນຫາ User ທີ່ຕ້ອງການລົບ, ກວດສອບລາຍລະອຽດສິດທິ ແລະ ຢືນຢັນການລົບອອກຈາກລະບົບ

ເບິ່ງຄູ່ມື (View)

3. ການກວດເບິ່ງຜູ້ໃຊ້ (View User)

ກວດເບິ່ງລາຍລະອຽດຂໍ້ມູນສ່ວນຕົວ, ສະຖານະບັນຊີ, 2FA, ສິດ Role ແລະ ວົງເງິນ Limit ຂອງ User

ເບິ່ງຄູ່ມື (View)

4. ການຣີເຊັດລະຫັດຜ່ານ (Reset Password)

ຣີເຊັດລະຫັດຜ່ານໃໝ່ໃຫ້ລູກຄ້າ Corporate ຫຼື Individual ແລະ ເລືອກສົ່ງທາງ Email / SMS

ເບິ່ງຄູ່ມື (View)

5. ວິທີການຣີເຊັດລະຫັດ Tpin (Reset Tpin)

ຣີເຊັດລະຫັດທຸລະກຳ 6 ຕົວເລກ (TPIN) ສຳລັບຜູ້ໃຊ້ Corporate ຫຼື Individual ຜ່ານ Email / SMS

ເບິ່ງຄູ່ມື (View)

6. ວິທີສົ່ງລະຫັດສ້າງບັນຊີຄືນໃໝ່ (Resend Create Password)

ສົ່ງລະຫັດຜ່ານສຳລັບຕັ້ງຄ່າບັນຊີໃໝ່ອີກຄັ້ງ ກໍລະນີລູກຄ້າບໍ່ໄດ້ຮັບຂໍ້ຄວາມທາງ Email / SMS

ເບິ່ງຄູ່ມື (View)

7. ການລ໋ອກ ແລະ ປົດລ໋ອກ User (Lock/Unlock User)

ປ່ຽນສະຖານະບັນຊີຜູ້ໃຊ້ລະຫວ່າງ Active (ປົດລ໋ອກ), Inactive (ປິດຊົ່ວຄາວ) ຫຼື Lock (ລ໋ອກບັນຊີ)

ເບິ່ງຄູ່ມື (View)

8. ການປ່ຽນສິດຜູ້ໃຊ້ເປັນປະທານ (Change Chairman)

ໂອນຍ້າຍ ຫຼື ປ່ຽນສິດປະທານບໍລິສັດ (Chairman Role) ໄປໃຫ້ User ຄົນໃໝ່ພາຍໃນບໍລິສັດ

ເບິ່ງຄູ່ມື (View)

9. ການປ່ຽນຊື່ຜູ້ໃຊ້ (Change Username)

ປ່ຽນຊື່ບັນຊີຜູ້ໃຊ້ (Username) ໃໝ່ ແລະ ຢືນຢັນຊື່ຜູ້ໃຊ້ໃໝ່ໃຫ້ກັບລູກຄ້າ

ເບິ່ງຄູ່ມື (View)

10. ການສ້າງ User ຜູ້ໃຊ້ເປັນປະທານ (Create Chairman)

ກຳນົດ ແລະ ສ້າງສິດຜູ້ໃຊ້ໃຫ້ເປັນປະທານບໍລິສັດ (Chairman) ຜ່ານເມນູ User Control

ເບິ່ງຄູ່ມື (View)

ຄູ່ມືຊຳລະບິນປີ້ເຮືອບິນ ລາວເດີນອາກາດ

ຂັ້ນຕອນການຈອງ ແລະ ຊຳລະບິນປີ້ເຮືອບິນ Lao Skyway ຜ່ານແອັບມືຖື MeBank Client ຄົບທັງ 9 ຂັ້ນຕອນ.

ເບິ່ງຄູ່ມື (View)
