ພາບປະກອບຕອນທີ 1 (Screen 1 View)
1

ຂັ້ນຕອນທີ 1: ກົດເລືອກເມນູ "ຊຳລະບິນ" (Bill Payment) ຢູ່ແຖບ Header ດ້ານເທິງ

ຢູ່ເທິງສຸດຂອງໜ້າຈໍໃນແຖບເມນູຫຼັກ (Navigation Bar), ໃຫ້ຄລິກເລືອກເມນູ "ຊຳລະບິນ" (ໄອຄອນຮູບໃບບິນສີເຫຼືອງ ຖັດຈາກເມນູ "ໂອນເງິນ"). ເມື່ອຄລິກແລ້ວ ລະບົບຈະພາທ່ານເຂົ້າສູ່ສູນກາງການຊຳລະຄ່າບໍລິການຕ່າງໆ.

2

ຂັ້ນຕອນທີ 2: ເລື່ອນລົງມາທີ່ໝວດ "ຈອງປີ້ເຮືອບິນ" ແລ້ວກົດ "ລາວເດີນອາກາດ" (Lao Skyway)

ໃນໜ້າຊຳລະບິນ ໃຫ້ເລື່ອນລົງມາຫາໝວດ "ຈອງປີ້ເຮືອບິນ" (Flight Booking), ຈາກນັ້ນກົດເລືອກທີ່ໂລໂກ້ "ລາວເດີນອາກາດ" (Lao Skyway) (ໄອຄອນຮູບນົກສີຂຽວ) ເພື່ອກ້າວເຂົ້າສູ່ໜ້າລະບົບຄົ້ນຫາ ແລະ ຈອງປີ້ໂດຍສານ.

2

Fill Flight Details, Click Search Flight, Select Ticket, and Click Continue

ພາບປະກອບຕອນທີ 2 (Screen 2 View)

ອະທິບາຍລະອຽດທຸກຊ່ອງຂໍ້ມູນ (Field-by-Field Breakdown)

1. ປະເພດການເດີນທາງ Trip Type
ເລືອກ: "ຖ້ຽວດຽວ" ຫຼື "ໄປ-ກັບ"

• ຖ້ຽວດຽວ (One-Way): ສຳລັບການເດີນທາງຂາໄປພຽງຢ່າງດຽວ (ຕົວຢ່າງເລືອກຖ້ຽວດຽວ ພ້ອມເຄື່ອງໝາຍຕິກຖືກ).
• ໄປ-ກັບ (Round-Trip): ສຳລັບການເດີນທາງທັງຂາໄປ ແລະ ຂາກັບ.

2. ຕົ້ນທາງ From / Origin
ຈາກ (Departure Airport)

ເລືອກສະໜາມບິນຕົ້ນທາງ, ຕົວຢ່າງ: VTE - Vientiane (ສະໜາມບິນສາກົນວັດໄຕ, ນະຄອນຫຼວງວຽງຈັນ).

3. ປາຍທາງ To / Destination
ເຖິງ (Arrival Airport)

ເລືອກສະໜາມບິນປາຍທາງ, ຕົວຢ່າງ: XKH - Xieng Khouang (ສະໜາມບິນແຂວງຊຽງຂວາງ).

4. ວັນທີເດີນທາງ Travel Date
ວັນທີເດີນທາງ (Date Picker)

ຄລິກໃສ່ປະຕິທິນເພື່ອເລືອກວັນ, ເດືອນ, ປີ ທີ່ຕ້ອງການບິນ, ຕົວຢ່າງ: 14/10/2026.

5. ຜູ້ໂດຍສານ Passengers
ຈຳນວນຜູ້ໂດຍສານ (Passenger Count)

ເລືອກຈຳນວນຄົນເດີນທາງ: 1 ຜູ້ໃຫຍ່, 0 ເດັກນ້ອຍ, 0 ເດັກອ່ອນ (ກົດເພີ່ມ/ຫຼຸດໄດ້).

6. ຊັ້ນໂດຍສານ Cabin Class
ຊັ້ນໂດຍສານທີ່ຕ້ອງການ (Class)

ເລືອກລະດັບຊັ້ນທີ່ນັ່ງ, ຕົວຢ່າງ: Economy (ຊັ້ນປະຢັດ).

7. ລະຫັດໂປຣໂມຊັນ Promo Code (Optional)
ລະຫັດໂປຣໂມຊັນ (Discount / Voucher)

ປ້ອນລະຫັດສ່ວນຫຼຸດພິເສດ (ຖ້າມີ). ຫາກບໍ່ມີ ແມ່ນສາມາດປະວ່າງໄວ້ໄດ້.

ຂັ້ນຕອນທີ 2: ກົດປຸ່ມ "ຄົ້ນຫາຖ້ຽວບິນ" (Click Search Flight)

ຫຼັງຈາກປ້ອນຂໍ້ມູນຄົບແລ້ວ, ໃຫ້ກົດປຸ່ມສີຂຽວເຂັ້ມ "ຄົ້ນຫາຖ້ຽວບິນ" ຢູ່ດ້ານລຸ່ມຂອງຟອມ ເພື່ອດຶງຕາຕະລາງຖ້ຽວບິນທີ່ວ່າງອອກມາສະແດງ.

ຂັ້ນຕອນທີ 3: ເລືອກຖ້ຽວບິນທີ່ຕ້ອງການ (Select Flight Card)

ຢູ່ຖັນດ້ານຂວາ ລະບົບຈະສະແດງຖ້ຽວບິນ LK212 (15:10 VTE → 15:45 XKH) ລາຄາ 710,000.00 LAK. ຄລິກໃສ່ກາດຖ້ຽວບິນນີ້.
